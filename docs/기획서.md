# 금욕 트래커 기획서

## 확정된 결정

| 항목 | 결정 |
|---|---|
| 형태 | iPhone용 PWA (홈 화면 추가), Xcode 불필요 |
| 스택 | 바닐라 HTML/CSS/JS, 빌드 도구 없음 |
| 저장 | 폰 localStorage만 사용 (서버·계정 없음) |
| 호스팅 | GitHub Pages (HTTPS 필요) |
| 범위 | 항목 여러 개, 실시간 경과 시간, 리셋, 최장 기록, 항목별 목표 일수 + 진행률(%), JSON 내보내기/가져오기 |

## 본문

- 항목: 이름 + 시작 시각 + 목표 일수(선택). 과거 시각 지정 가능.
- 카드: 경과 일/시/분/초, 최장 기록, 리셋 횟수. 목표가 있으면 "N일차 / 목표 M일 · P%"와 진행 막대.
- 목표: 항목 추가 때 입력, 카드의 "목표" 버튼으로 나중에 변경/해제. 리셋해도 유지.
- 리셋: 현재 기록이 최장보다 길면 갱신 후 지금 시각으로 재시작.
- 백업: JSON 내보내기/가져오기 (Safari 데이터 삭제 대비).

## 원칙

- 프론트 코드는 짧고 표준적으로 유지한다.

## 미결 사항

- 앱 이름·아이콘 톤
- 푸시 알림 (iOS 제약 있음)
- 스토어 배포 여부 (하면 Capacitor + Xcode + 연 $99)
