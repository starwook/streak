# 그냥 다 참는 거야 기획서

## 확정된 결정

| 항목 | 결정 |
|---|---|
| 형태 | iPhone용 PWA (홈 화면 추가), Xcode 불필요 |
| 스택 | 바닐라 HTML/CSS/JS, 빌드 도구 없음 |
| 저장 | 폰 localStorage만 사용 (서버·계정 없음) |
| 호스팅 | GitHub Pages (HTTPS 필요) |
| 범위 | 항목 여러 개, 실시간 경과 시간, 리셋, 최장 기록, 항목별 목표 일수 + 진행률(%), JSON 내보내기/가져오기 |
| 계급 | 사람당 1개(대표 계급), 항목은 점수에만 기여. 군 계급 12단계 + 점수에 따라 변하는 아바타 얼굴(SVG) |
| 점수 | 목표 달성 +목표일수, 목표 전 포기(리셋·삭제) −목표일수, 0 하한. 시간 경과만으론 오르지 않음 |
| 목표 | 필수, 최소 7일 |

## 본문

- 항목: 이름 + 시작 시각 + 목표 일수(필수, 7일 이상). 과거 시각 지정 가능.
- 카드: 경과 일/시/분/초, 최장 기록, 리셋 횟수, "N일차 / 목표 M일 · P%"와 진행 막대, 달성·포기 시 점수.
- 목표: 항목 추가 때만 입력, 이후 변경·해제 불가. 리셋해도 유지.
- 리셋: 현재 기록이 최장보다 길면 갱신 후 지금 시각으로 재시작. 리셋·삭제는 확인을 두 번 묻고, 감점·강등을 경고한다.
- 백업: JSON 내보내기/가져오기 (Safari 데이터 삭제 대비). 형식 `{ items, meta }`, 예전 배열 형식도 가져온다.

### 계급·점수 규칙

- 달성: 등록 시각(`createdAt`) 기준으로 목표 일수가 실제로 지나면 `+목표일수`, 항목당 1회. 과거 시작 시각으로 즉시 점수 받는 꼼수 방지.
- 포기: 달성 전 리셋/삭제 → `−목표일수`(0 하한). 달성 후 리셋/삭제는 감점 없음. 달성한 항목은 재도전해도 추가 점수 없음.
- 강등: 점수가 내려가 계급 구간 아래로 가면 자동. 최고 계급은 따로 기록해 보여준다.
- 계급표(초안): 훈련병 0 · 이병 7 · 일병 21 · 상병 45 · 병장 90 · 하사 150 · 중사 250 · 상사 400 · 소위 600 · 대위 900 · 소령 1300 · 대장 2000 (`rank.js`의 `RANKS`)
- 얼굴: 낮은 계급은 창백·다크서클·찡그림, 높을수록 혈색·미소, 소위 이상은 광채, 대장은 후광.
- 계산(`rank.js`)·그림(`avatar.js`)은 DOM 독립 — 멀티 채팅방에서 닉네임 옆 대표 계급·아바타로 재사용 예정.

## 원칙

- 프론트 코드는 짧고 표준적으로 유지한다.

## 미결 사항

- 계급 점수 구간·최소 목표 일수 확정, 아바타 화풍
- 달성 후 같은 항목 재도전(새 목표 부여) 허용 여부
- 멀티 채팅방: 서버·계정 필요(현재 "서버·계정 없음" 결정과 충돌), 점수 조작 방지(서버 계산), 항목 수 상한
- 앱 이름·아이콘 톤
- 푸시 알림 (iOS 제약 있음)
- 스토어 배포 여부 (하면 Capacitor + Xcode + 연 $99)
